# media/fx

Props transparentes sin marco: imagenes con canal alfa o video `.webm` con
transparencia. Se renderizan sin la tarjeta de vidrio que usa `media/misc`,
pensados para superponerse directo sobre la camara.

Este repo no trae assets reales. Coloca tus propios archivos en esta carpeta;
el servidor solo permite mostrar archivos que esten dentro de la raiz de media
configurada (ver `docs/07-servidor-protocolo-ia-seguridad.md`, "media airlock").

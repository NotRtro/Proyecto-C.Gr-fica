# media/misc

Imagenes normales para el tablero (`add_img`, `hand`, `give`).

Se renderizan con marco de vidrio (tarjeta translucida alrededor de la imagen).
Formatos soportados: `.png`, `.jpg`, `.jpeg`, `.webp`, `.gif`.

Este repo no trae assets reales. Coloca tus propias imagenes en esta carpeta;
el servidor solo permite mostrar archivos que esten dentro de la raiz de media
configurada (ver `docs/07-servidor-protocolo-ia-seguridad.md`, "media airlock").
